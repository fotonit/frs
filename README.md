# 🌿 ЭкоБаллы

Студенческая инициатива из Санкт-Петербурга: выполняй экологические задания, проходи экотест, копи виртуальные баллы (ЭБ) и открывай достижения.

> Учебный прототип. Баллы виртуальные, действия подтверждаются самостоятельно, сервер не нужен.

## Возможности

- **10 экологических заданий** с фильтром по категориям (сортировка, привычки, сообщество)
- **5 уровней** и индикатор прогресса до следующего
- **6 достижений** с подсказками, как их открыть
- **Экотест** из 5 вопросов с пояснениями к ошибкам (награда +20 ЭБ при 4+ верных ответах)
- **Сортировка отходов**: справочник и мини-игра «куда это выбросить?»
- Демонстрационный рейтинг (участники вымышлены)
- Прогресс сохраняется в `localStorage` — данные никуда не отправляются
- Адаптивная вёрстка, навигация по ссылкам (работает кнопка «Назад»), доступность с клавиатуры

## Запуск

Откройте `index.html` в браузере — сборка и сервер не нужны.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в корень файлы `index.html`, `style.css`, `script.js`, `README.md`.
2. **Settings → Pages → Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Структура

| Файл | Назначение |
|---|---|
| `index.html` | каркас страницы и мета-теги |
| `style.css` | стили (адаптивные, с учётом `prefers-reduced-motion`) |
| `script.js` | данные, страницы, логика баллов и сохранение |

## Как добавить задание

В `script.js` добавьте объект в **конец** массива `TASKS` (порядок менять нельзя — в `localStorage` хранятся номера заданий). Не забудьте обновить условие достижения «Экомарафон», если число заданий изменилось.

## Ограничения

- Прогресс привязан к браузеру и устройству
- Рейтинг демонстрационный
- Социальный эффект проекта пока не измерен
